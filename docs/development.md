# Local development

The application uses React, TypeScript, Vite, and React Three Fiber. Installation, validation, and hosting details live here rather than in the visitor-facing README.

Use Node 22 as specified in `.nvmrc`.

```sh
npm ci
npm run dev -- --port 8001 --strictPort
```

The development server binds to `0.0.0.0`. Open the local URL printed by Vite. Network access depends on your host's firewall and port forwarding.

```sh
npm test
npm run format:check
npm run build
```

Build output is generated in `dist/`. It and local dependencies are ignored. `SESSION_NOTES.md` is local working context and must not be staged or referenced by CI.

For optional browser checks, install Python Playwright and provide Chromium. Set `CHROMIUM_PATH` to its executable if different from `/snap/bin/chromium`, and `APP_URL` if different from `http://127.0.0.1:8001/`.

Current browser checks:

- `scripts/browser-authenticity-check.py` — withdrawn materials stay unavailable.
- `scripts/browser-environments-check.py` — room selection and accessible tours.
- `scripts/browser-elementary-check.py` — new activity completion, reset, examples, and touch interaction.
- `scripts/browser-feedback-check.py` — requested observations and completion messages.
- `scripts/browser-map-geometry-check.py` — continent rendering and fitting.

Some older browser scripts target retired or withdrawn prototypes; see their docstrings before running them.

Further documentation: [architecture](architecture.md), [activity roadmap](activity-roadmap.md), [elementary materials and geography assets](elementary-activities.md), and [deployment](deployment.md).

The original SVG branding is in `public/brand/`. The standalone mark is used in the app and as the favicon; the horizontal logo is used in the README. Asset URLs in the app honor Vite's deployment base path.

The wordmark uses outlined DM Sans lettering, generated by `scripts/build-wordmark.py`. The font is from the Google Fonts DM Sans project under SIL OFL 1.1; see the adjacent typeface license in `public/brand/`. Outlines keep the README logo consistent without external font loading.
